# Desert Quiet

لعبة تصويب وتسلل خيالية بمنظور الشخص الثالث، تدور أحداثها في بيئة صحراوية. الهدف هو بناء نسخة Android باستخدام Unity.

## حالة المشروع
هذه بداية هيكل مشروع Unity وليست نسخة لعبة مكتملة أو APK. لم يتم بعد فتح المشروع داخل Unity Editor أو تجميعه أو اختباره على جهاز Android.

## بيئة التطوير
- Unity 2022.3 LTS
- Universal Render Pipeline (URP) 14
- المنصة المستهدفة: Android
- اتجاه الشاشة: أفقي (Landscape)
- اللغة الأساسية للواجهة: العربية

## محتويات البداية
- `Assets/Scripts/Core/GameBootstrap.cs`: نقطة تهيئة بسيطة للمشهد.
- `Assets/Scripts/Player/ThirdPersonMobileController.cs`: أساس تحكم شخصية قابل لاستقبال إدخال عصا لمس افتراضية.
- `Packages/manifest.json`: اعتماد URP.
- `ProjectSettings/ProjectVersion.txt`: إصدار Unity المستهدف.

## فتح المشروع
1. افتح المشروع في Unity Hub باستخدام Unity 2022.3 LTS.
2. ثبّت Android Build Support وAndroid SDK & NDK Tools وOpenJDK.
3. أنشئ المشاهد والأصول المطلوبة داخل مجلد Assets.
4. اختبر المشروع في المحرر قبل إعداد بناء Android.

## خطة التطوير
1. مشهد اختبار صحراوي وتحكم اللاعب والكاميرا.
2. واجهة لمس عربية ومنظار القنص.
3. الحراس وأنظمة الرؤية والإنذار والتخفي.
4. المهمة الأولى: إنقاذ في الصحراء.
5. المركبات والحفظ والطقس والعالم الموسع.
6. تحسين الأداء وإعداد Android وبناء APK.
